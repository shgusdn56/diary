휴대폰 알림

휴대폰 Claude 앱으로 받는 알림을 한곳에서 설정해요.

수정 알림 다른 사람이 생활일지를 고치면 알려 줘요
휴대폰 알림 받기
켜 두면 다른 사람이 일지를 고쳤을 때 아래 정한 때마다 내 휴대폰 Claude 앱으로 “몇 시에 누가 어디를 뭐라고 고쳤는지” 알림이 와요. 고친 게 없으면 알림이 오지 않아요. 일지를 열어 두고 있으면 위쪽 알림 종에 바로 떠요. 내가 고친 건 알리지 않아요.
정한 때마다(가장 짧게 1시간마다) 다른 사람이 수정한 기록을 확인해서, 있으면 내 휴대폰 Claude 앱으로 알림이 와요. Claude 예약 작업은 1시간보다 자주 돌릴 수 없어서, 바로 보려면 일지 위쪽 알림 종을 확인해요. 내가 수정한 건 알리지 않아요.
처음 한 번만 휴대폰 알림 화면의 '저장'을 누르면 알림 예약이 바로 만들어져요. 안 되면 아래 버튼으로 설정 문구를 복사해 Claude Code(claude.ai/code)의 새 작업에 보내요(보통 Claude 채팅에서는 예약 작업을 못 만들어요).
알림 받는 때부터각자 정해요. 정한 시각마다 그동안 다른 사람이 고친 걸 모아서 알려 주고, 고친 게 없으면 오지 않아요. 저장하면 내 Claude 계정에 알림 예약 작업이 바로 만들어지거나 바뀌어요(처음 한 번 연결 허락만).
일정요약 예약발송 그날 일정만 아침에 보내 줘요 (각자 내 Claude 계정에 설정)

제작자

고른 사람의 화면을 그대로 띄워요. '폰'은 휴대폰처럼 동작해서 터치하면 화면 키보드가 떠요(터치 되는 노트북·태블릿). 지금 일지 내용을 복사해 쓰는 테스트 화면이라 여기서 고친 건 저장되지 않고, 메일·예약 작업도 실제로 보내지 않아요.

쪽지
